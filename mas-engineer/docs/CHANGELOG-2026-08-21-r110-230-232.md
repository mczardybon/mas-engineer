- For CI: use `tools/mas_e2e_pty_test.sh` (PTY-shell wrapper, 129 recipes)

  with `MAS_AUTO_CONFIRM=1` in foreground-PTY terminal

  defib-block as known environmental limit (132/132 PASS, 0 fail)
