## 3-source ⚡ emoji allowlist sync (R110-78 lesson applied)

The root cause for the 2 alignment-test failures in v7 was a NEW
emoji category (`⚡` for performance/optimization) that was
introduced for the R110-491 commit subject, but only added to ONE
source. The other 2 sources still had the old 5-emoji allowlist.

Per R110-78 lesson: when a format has 3 sources (validator, detector,
skill table), all 3 must be updated atomically, or the next commit
with the new format will drift.

| `recipe/instructions/sub_mas-pre-push-validator.md`       | 5 emojis        | 5 + ⚡                       |
