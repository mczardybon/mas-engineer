  by reading the source file. So actual covered code = ~0%.

    `CalledProcessError` (not a git repo), malformed lines
    (empty + 2-part), valid 3-part line with `\x1f` separator
  - `classify_drift()`: 6 paths (cutoff exempt, prefix exempt
    (Merge/Revert/[auto]/[bot]/test commit/'test'/[MAS-ENGINEER]),
    noise exempt (wip/tmp/draft exact-match-lowercased), regex
    conform (with+without scope), emoji conform (4 emojis), drift
    (random subject + `wrench:` legacy))
  - `format_human()`: empty report, with drift, with exempt,
    `<unset>` cutoff marker, hash shortened to 8 chars
  - `main()`: --path, --since, --convention-since, --json, exit
    codes 0/1/2, since too small, since negative, git log failure,
    `if __name__ == "__main__":` guard

- **Why it matters:** A regression in `classify_drift()` would
  silently re-introduce the R110-130 `wrench:` exemption, or
  re-introduce the R110-258 spec gap (Check 1.5 ↔ Check 16+).
  A regression in `format_human()` would break the human-readable
  report consumed by reviewers during sprint retros. A regression
  in `main()` would break the cron/CI exit-code contract (0/1/2).
