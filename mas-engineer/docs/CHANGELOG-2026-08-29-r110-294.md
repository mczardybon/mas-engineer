## Pitfalls discovered + fixed during dev

1. **monkeypatch REPO_ROOT alone is not enough** — module also
   caches `DEFAULT_LOG_DIR` at import time. Need to monkeypatch
   both. (Test fixed.)
2. **`if __name__ == "__main__":` does NOT call sys.exit()** —
   just prints JSON to stdout. Use `runpy.run_module(...)` without
   `pytest.raises(SystemExit)`. (Test fixed.)
3. **import dev_message_queue is INSIDE process_msg()** — not
   at module top — so test environment can use a mock. Required
   to test escalation without setting up the full MQ runtime.
4. **Escalation payload shape** (R110-169 contract) has nested
   `summary.degraded_levels` derived from `_digest_levels()`
   ok-false entries — verify exactly: `["checkpoint"]`.
5. **`ensure_ascii=False` in BOTH writes** (R110-270) — original
   write + re-write after escalation. Test verifies unicode
   in `from` field is preserved (e.g. `α-User-α` not `\u03b1`).
6. **`log_dir` outside `REPO_ROOT`** → `relative_to()` raises
   `ValueError` → fall back to `str(log_path)`. Test verifies
   the result starts with `/` (absolute path).
