## Changes

### `recipe/instructions/sub_mas-pre-push-validator.md` (+24/-3)

**1. Check 17 pytest invocation** — add `--timeout=300 --ignore=.state`:

```bash
# Before (R110-78 to R110-254, no timeout):
python3 -m pytest tests/ -q --tb=line --color=no

# After (R110-255, defensive timeout matching ci-tests.yml R110-246):
python3 -m pytest tests/ -q --tb=line --color=no --timeout=300 --ignore=.state
```

**Why:**
- `--timeout=300` matches ci-tests.yml (R110-246). Without it, a slow CI
  runner could exceed the inner `subprocess.run(timeout=180)` for phoenix
  tests and pytest would have no upper bound. Defensive consistency with
  the GHA workflow.
- `--ignore=.state` makes explicit that .state/ is transient run-state
  (R110-247), not test code. The validator's other pytest invocations
  (Check 1.5) already use this flag.

**2. Check 17 duration spec** — retire R110-95 9.65s, add R110-255 baseline:

```markdown
# Before:
**Duration reference (R110-95, 2026-08-04, 5x measurement):**
  Median: 9.65s | Mean: 9.60s | Std: 0.13s | Range: 9.46-9.77s
  Historical: 8.12s (R110-71 era, single-point). Spec is documentation-
  only; Check 17 does NOT BLOCK on duration. Variance is real (run-to-run
  ~0.3s); the 8.12s figure is now retired.

# After:
**Duration reference (R110-95, 2026-08-04, 5x measurement, BEFORE phoenix tests):**
  Median: 9.65s | Mean: 9.60s | Std: 0.13s | Range: 9.46-9.77s
  Historical: 8.12s (R110-71 era, single-point). Spec is documentation-
  only; Check 17 does NOT BLOCK on duration. Variance is real (run-to-run
  ~0.3s); the 8.12s figure is now retired.

**Duration reference (R110-255, 2026-08-22, AFTER R110-239 phoenix tests added):**
  The 4 phoenix-recovery tests in tests/test_dev_phoenix_recovery_publish.py
  each take ~73-76s wallclock (subprocess.run(timeout=180) on
  dev_phoenix_recovery_run.py which runs all 5 phoenix levels). Total
  phoenix cost: 4 × 75s = 300s. The other ~1620 tests run in ~130s.
  Full test-suite wallclock: 420-450s (7-7.5 min) single-process.
  Spec is documentation-only; Check 17 does NOT BLOCK on duration.
  Measured R110-254 (2026-08-22): 1625 passed in 7m 16s (436s) local.
  Measured R110-254 (2026-08-22): GHA matrix job 14m 32s wallclock.
  (The R110-95 9.65s figure is RETIRED as of R110-255 — superseded
  by the post-phoenix baseline above. Do NOT cite 9.65s for any
  pre-2026-08-22 commits. Use 7-7.5 min local, 14-15 min GHA.)
```

**Why:** R110-95 spec was honest at the time (1277 tests, no phoenix).
R110-239 added 4 phoenix tests that each take ~75s. The 9.65s figure
is now wrong by ~40×. Citing it in any post-R110-239 commit is a
spec-drift bug. R110-255 retires the old figure and adds the new
post-phoenix baseline so future commits can cite reality.
